## ✨ Overview
This repository contains two major machine learning projects packaged as ZIP files for easy download and exploration:

- 📸 **Image Classification** → Computer vision models for recognizing and categorizing images.  
- 💬 **Sentiment Analysis** → Natural Language Processing pipeline for classifying text sentiment (positive/negative/neutral).  

---

## 🛠 Tech Stack
- **Languages**: Python  
- **Libraries**: NumPy, Pandas, Scikit‑Learn, Matplotlib, Seaborn, TensorFlow/Keras  
- **Tools**: Jupyter Notebook, Git LFS (for large datasets/models)

## 🚀 Getting Started
Clone the repo:
git clone https://github.com/Divyanshi12coder/Machine-Learning.git
cd Machine-Learning

Install dependencies:
pip install -r requirements.txt

Run a sample notebook:
jupyter notebook notebooks/Image-Classification.ipynb
